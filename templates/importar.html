{{ ico('download') }} Baixar modelo
  1. Baixe o modelo e preencha uma linha por item. Só Código e Descrição são obrigatórios.
  2. Se o código já existir, os dados do cadastro são atualizados (o saldo não muda — exceto o saldo inicial de itens que ainda não tiveram nenhuma outra movimentação, que pode ser corrigido reenviando a planilha).

Lançar saídas em lote

Registre várias saídas de material de uma vez (Excel ou CSV)

{{ ico('download') }} Baixar modelo de saídas
  1. Baixe o modelo: ele já traz a lista dos itens cadastrados e o saldo atual.
  2. Preencha uma linha por saída. Só Código e Quantidade são obrigatórios; sem data, vale hoje.
  3. As saídas entram na ordem das linhas. Se o saldo não bastar, a linha é ignorada e o motivo aparece no resultado.
  4. Cada saída pode ser estornada depois em Movimentações.
